# Jogo_JS
Este é um jogo simples e divertido desenvolvido com HTML, CSS e JavaScript, onde o objetivo é eliminar os mosquitos que aparecem aleatoriamente na tela utilizando uma raquete controlada pelo jogador. O game possui três niveis de dificuldade, podendo ser escolhida pelo jogador.

O jogo termina quando as vidas, no total 3, ou o tempo termina.
